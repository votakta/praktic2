Система искусственного интеллекта для автоматического обнаружения мобильных телефонов на экзаменационных изображениях.

Технологии

- **Python** — язык программирования
- **Flask** — веб-фреймворк
- **YOLOv8** — нейросеть для детекции объектов
- **OpenCV** — обработка изображений
- **SQLite** — база данных
- **HTML + CSS + JavaScript** — пользовательский интерфейс
